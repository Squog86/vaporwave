# Vaporwave: Aesthetic of Nostalgia

## Accessibility Fixes (WAVE & WCAG AA)
- I added descriptive `alt` text to all images across the site so screen readers can accurately describe the visuals.
- I updated the text and background color hex codes in `style.css` to meet a minimum 4.5:1 contrast ratio for WCAG AA compliance.
- I added `lang="en"` to the opening `<html>` tag on all three pages to specify the document language for assistive technologies.
- I associated every form input with a `<label>` element and added `aria-describedby` error messages on the About/Contact page.

## Visual Design & Gestalt Principles
- **Proximity:** I used proximity by grouping related album art, titles, and descriptions together inside bordered cards with tight internal spacing and wider margins between separate cards.
- **Similarity:** I used similarity by applying a consistent vaporwave color palette, retro font styling, and matching border treatments to all navigation links, section headers, and buttons across all three pages.
